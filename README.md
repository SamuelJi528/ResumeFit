# ResumeFit

ResumeFit helps students and recent graduates understand how their resume connects to a job description. It compares the experience already shown, highlights gaps, and suggests clearer wording for existing bullet points.

**[Try ResumeFit](https://resumefit-topaz.vercel.app/)**

## Features

- **Upload or paste a resume** in PDF, DOCX, or UTF-8 TXT format.
- **Compare it with a job description** to get a summary and prioritized improvements.
- **Inspect the evidence** behind requirements labeled Supported, Partial, or Not shown.
- **See requirement coverage** with a weighted percentage and counts of supported requirements and gaps.
- **Improve existing bullet points** with side-by-side suggestions and explanations.
- **Refine suggestions** with requests such as "Make it shorter" and review previous versions.
- **Download a text report** containing the review, evidence, suggestions, and revision history.
- **Explore with sample inputs** and toggle example-guided feedback to compare prompt behavior.

The responsive workspace includes editable inputs, result tabs, character counts, and feedback when a review no longer matches the current inputs.

## Try it out

1. Open the [website](https://resumefit-topaz.vercel.app/) and load the sample inputs, or add a resume and job description.
2. Click **Review my resume**.
3. Explore the requirements, bullet suggestions, and improvements.
4. Refine a suggested bullet or select **Download review** to save the results.

Visitors do not need their own Gemini API key. The sample inputs are fictional; reviews are generated by Gemini rather than loaded from canned answers. Generation depends on available API quota. If the site requests a demo access code, obtain it from the project owner.

## How it works

The browser sends the input text to a Flask backend, which calls the Gemini API and validates the structured response. The review checks whether quoted evidence appears in the supplied documents and rejects new numeric strings in rewritten bullets. Invalid output gets one repair attempt.

Requirement coverage is calculated from the extracted requirements: Required items have weight 2 and Preferred items weight 1; Supported earns full credit, Partial half, and Not shown zero. **It is not an ATS score or a hiring prediction.**

## Prompt engineering

ResumeFit uses three prompt engineering techniques, implemented in [prompts.py](prompts.py):

1. **Persona prompting:** Gemini is instructed to act as a recruiter helping students and recent graduates. It gives practical feedback based on the resume and job description, using the supplied experience as evidence and preserving the applicant's actual role.
2. **Few-shot prompting:** Two examples show how to evaluate resume evidence, distinguish supported experience from gaps, and improve bullet points without inventing experience. These examples are included when **Use example-guided feedback** is enabled in the workspace.
3. **Iterative refinement:** Users can request changes such as "Make it shorter." Gemini receives the original bullet, its latest suggested version, and the user's feedback to produce another version, with the original text serving as the factual reference.

## Limitations and privacy

- AI feedback can be inaccurate. Source checks do not verify every interpretation or prevent every invented claim; review suggestions before using them.
- Files are limited to 3 MB, and PDFs to 12 pages. Resume text must contain 100 to 12,000 characters; job descriptions must contain 100 to 8,000 characters.
- Scanned PDFs need OCR outside the app. Imported text from complex layouts may need correction.
- Reviews and refinements send text to Google's Gemini API. Use fictional or redacted inputs when exploring the demo.
- There are no user accounts or saved review database. The workspace lives in the current browser tab and resets on page reload; download a report to keep it.
- Editing the inputs pauses refinement until a new review is generated or the reviewed inputs are restored.

Developers can run the app with Python 3.11 or newer and a Gemini API key. See the [development guide](docs/DEVELOPMENT.md) for installation, local configuration, tests, and the source layout. Windows users can also use `run_windows.bat` after configuring their local environment.

## Project background

ResumeFit was built for the CS4680 AI Assistant Project to explore practical prompt engineering through resume feedback. It uses an existing model and does not train one.
