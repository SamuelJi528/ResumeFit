    ABOUT THE PROJECT

    Useful feedback starts
    with real evidence.

    ResumeFit is a CS4680 project that uses prompt engineering to help students describe their existing experience more clearly.

    How the AI is guided

    Persona: The model acts as a recruiter helping students and recent graduates.

    Few-shot: Two examples show how to compare requirements, use source excerpts, and rewrite bullets. You can switch examples off for a comparison.

    Iterative refinement: A rewrite uses the original source, the previous draft, and your requested change.

    What the coverage number means

    Required items have weight 2; preferred items have weight 1. Supported gets full credit, Partial gets half, and Not shown gets zero. The extracted requirements and their interpretation can vary by model.

    Your documents and data

    Your text is sent through this website's server to Google's Gemini API. The app has no resume database and does not intentionally save uploaded files. Google processes API inputs under the project's applicable terms; free-tier content may be used to improve its products.

    Document text and results remain in this browser tab while it is open. Clear removes the current workspace. Always check suggestions before using them, and use redacted documents for a public demo.
